# Original Mr. Runner Plus payload

`Payload/Mr.Runner Plus.app` holds the original game's executable, scripts, music, graphics, and bundled resources. Signing, provisioning, purchase/account, and metadata sidecars are excluded. The input is pinned in `payload-sha256.json` and the build reconstructs the guest archive locally.
